# Changesets

Hello and welcome! This folder has been automatically generated by
`@changesets/cli`, a tool that manages versioning and changelogs. Read the full
documentation at https://changesets.dev.

Studio keeps one changeset per behaviour-changing pull request. Run
`pnpm changeset` to create one, then commit the generated Markdown file with your
changes. See [docs/releasing.md](../docs/releasing.md) for the full release
process.

Quick questions are answered in the
[Changesets FAQ](https://changesets.dev/faq).
